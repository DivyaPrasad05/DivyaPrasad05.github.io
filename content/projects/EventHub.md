title: EventHub
---

Event Hub is an Android app developed in Android Studio that connects people together. As an attendee, you can sign up for events by simply scanning a QR code. As an organizer, you can set up custom events with its own unique QR code. As an admin, you have full access to add and remove anything in the app (typical admin duties).

We used Java in Android studio to create the app and used Google Firebase to store all of the data. We also used Figma to create the mockups.

This app was our term project for [CMPUT 301: Introduction to Software Engineering](https://apps.ualberta.ca/catalogue/course/cmput/301).  We built it in a team of 5.

Check out the Github repo [here](https://github.com/EventHubApp/Event-Hub)
