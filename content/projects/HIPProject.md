This was my intern project for when I did the High School Internship Program (HIP). 

We created a webapp that gamifies drinking water using some foundational basic concepts from reinforcement learning. We used Django for the backend and vanilla HTML, CSS, and JavaScript for the frontend. 

We had a plant that would slowly die throughout the day if the user didn't drink enough water.

Check out the Github repo [[here]](https://github.com/YoyoLiuuu/DrinkingWaterWebApp)
