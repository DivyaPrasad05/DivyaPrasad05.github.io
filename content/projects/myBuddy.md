This project was submitted to the Arcurve Health Hack 2024.

We built a webapp that is designed to help kids feel more comfortable in expressing their emotions. We gamified the whole experience and created a mascot named PoPo using AI image generation from DALL E to which the kids can talk to.  

We also used React for the frontend of our webapp and the OpenAI GPT-4 model for the text generation spoken by PoPo.

Super cool experience and had so much fun collaborating with people that I had never met prior :)

Check out the Github repo [here](https://github.com/DivyaPrasad05/AlbertaHealthHack24)

Check out the [Devpost](https://devpost.com/software/mybuddy-15o0uy) for a live demo!
