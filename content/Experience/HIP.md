- One of 30 high school students chosen all across Alberta to conduct paid research in the HIP Program
- I was placed in the Alberta Machine Intelligence Institute (Amii) where I have used HTML, CSS, Django to create a web application that helps users to drink more water.
- We achieved this by using a Firebase database to store user information and running periodic push notifications to remind users to drink more water

Read more about my intern project [[HIPProject|here]] and check out the [Github repo](https://github.com/YoyoLiuuu/DrinkingWaterWebApp)
